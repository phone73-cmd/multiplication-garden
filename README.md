- 받아쓰기는 부모 앱의 입장 확인 후 초기화. 직접 주소로 접근하면 공통 로그인으로 이동. 학습 중 홈 이동 시 확인. 음성 예약과 재생은 화면 이동 시 취소.
- 기존 garden-history와 dictation-* 저장 키를 그대로 유지. 같은 브라우저·같은 origin이면 기존 자료를 읽으며 다른 origin의 자료는 자동 이전되지 않음.
- 홈의 전체 학습 백업은 문장·설정·수학/국어 기록을 JSON으로 내보내고 검수 후 가져옴. 기존 받아쓰기 .txt 문장 백업은 과목 설정에서 계속 가져오기 가능. 저장 실패 시 이전 값을 되돌리도록 처리.
- 수학 골고루 서술형 10문제에 1개, 20·30문제에 2개. 오류 고치기는 숫자 답만 입력·자동 채점. 20·30문제는 19유형 모두 포함.
- 채점 화면은 미확인 서술형, 틀린 문제, 접힌 맞힌 문제로 모아 표시. 확인한 서술형은 별도 접힘 표시, 오답 판정 시 틀린 문제로 이동. 문항 번호와 중복 없는 표시 유지.
- 받아쓰기 문장 편집과 가져오기 100자 기준 통일. 엄격 채점 시 연속/앞뒤 공백을 임의로 정리하지 않음.
- 통합 서비스워커는 learning-garden- 캐시와 명시한 앱 파일만 관리. 다른 앱 캐시를 삭제하지 않음. 받아쓰기 자체 서비스워커는 등록하지 않음. 온라인 최초 접속·설치가 끝난 뒤 두 과목을 오프라인에서 열 수 있음. 음성은 기기의 설치 음성에 따라 오프라인 가능 여부가 다름.
- 당겨서 새로고침은 안내 문구 없는 파스텔 바. 현재 입력과 화면 유지. 새 배포 파일을 받으려면 브라우저에서 페이지 새로고침.

## v1.5.1

## v1.4.0
- 19유형: 0·1의 곱, 인수 빈칸, 곱셈표, 크기 비교, 몇 배, 오류 고치기, 계산 설명, 이야기 만들기, 가능한 식 모두 고르기 추가.
- 같은 곱: 서로 다른 인수 조합을 최소 두 짝 포함하고 순서 교환도 구분해 연습. 5·7단처럼 다른 조합이 없는 경우에는 다른 단 문제임을 안내.
- 복수 선택: 정답 개수 1~3개, 오답 설명 다양화. 2~9단 보기에서 ×10을 제외.
- 조건: <, ≤, >, ≥, 범위 조건을 실제 후보 집합으로 검수. 정답이 하나이며 각 조건이 답을 좁히는 역할을 하도록 생성. 5·7단은 다른 단과의 공통 곱이 하나뿐이므로 홀수·짝수 조건을 활용.
- 20문제 골고루: 기본 10, 응용 6, 설명 4. 10·30문제도 같은 비중으로 구성하며 20·30문제는 19유형 모두 포함. 학교의 공식 출제 비율이 아닌 앱의 구성안.
- 각 유형에서 단과 곱하는 수를 순환 배분하고 완전히 같은 문제의 재출제를 최소화. 작은 문제 풀이에서는 가능한 조합 수에 따라 반복될 수 있음.
- 이동 문제: 전체 거리, 이동 횟수, 한 번의 거리로 질문 방향을 바꿈. 한 번의 거리를 묻는 그림에서는 구간 거리 숫자를 감춤.
- 그림의 묶음 순서를 요구하는 문제와 전체 개수를 구하는 문제의 채점 기준을 분리. 전체 개수 문장제는 두 인수 순서 교환 인정.
- 설명은 예시 문장과 자동 대조하지 않음. 보호자가 기준을 보고 뜻이 맞는지 확인한 후 최종 점수 저장. 재확인·당겨서 새로고침 시 평가 기록을 중복 저장하지 않음.
- 생활 문장제 20소재. 숫자판 5열×6행 오름차순, 작은 답칸, 홈 아이콘, 파스텔 새로고침 바, 기존 garden-history 기록 유지.

## 통합 구조
- `index.html`, `app.js`, `questions.js`: 공통 로그인과 수학 학습.
- `study.js`: 과목 선택, 공통 이동, 결과 그룹, 전체 백업·가져오기.
- `dictation/index.html`: 업로드된 받아쓰기 공책의 격리된 HTML/CSS/JS 모듈. 스타일·전역 변수 충돌을 막기 위해 같은 origin의 iframe에서 실행.
- `sw.js`, `manifest.webmanifest`: 배움정원 공통 설치·오프라인 파일 관리.
- `tests/questions.cjs`, `tests/integration.cjs`: 문항·화면 제어·백업·받아쓰기·캐시 범위 검사.

개인용 정적 입장 잠금이며 서버 인증이 아닙니다. 공개 저장소의 소스에서는 입장 비밀번호를 확인할 수 있습니다.
