# 곱셈 정원 v1.3.5
초등학교 2학년 곱셈 단원평가 연습 앱. 정적 웹앱이며 브라우저 localStorage에 평가 점수만 저장합니다. 기존 garden-history 기록을 유지합니다.

## v1.3.5
- 조건에 맞는 수: 비교 기준과 같은 수까지 포함해 출제하고, 조건을 만족하는 수는 하나만 나오도록 조정.
## v1.3.4
- 홈 화면 아이콘을 전체 캔버스형으로 조정해 안쪽 원형 여백을 제거.
## v1.3.3
- 당겨서 새로고침 시 안내 문구 없이 상단에 부드러운 파스텔 진행 막대만 표시. 현재 화면과 입력 상태 유지.
## v1.3.2
- 화면 맨 위에서 아래로 당기면 새로고침하며 현재 화면을 유지. 진행 중 문제의 입력 답안과 홈 설정도 보존하고, 평가 점수 중복 저장을 방지.
## v1.3.1
- 숫자판 30칸을 작은 수부터 큰 수 순서로 표시.
- 문제 수 선택은 10·20·30문제만 제공.
- 곱셈식을 주어로 쓸 때 받침에 맞춰 은/는을 사용 (예: 6 × 7은). 방법 ②는 목적격 조사 대신 “값에 …만큼 더하는” 문장으로 표현.
## v1.3.0
- 그림 보고 덧셈식·곱셈식 완성하기 / 그림 보고 곱셈식 만들기를 독립 선택 항목으로 분리.
- 꽃·사탕·사과·공·연필·장난감 자동차·딸기·별·귤·곰 인형의 그림과 설명 복수 선택.
- 숫자판: 5열×6행 30칸, 해당 단 1~9배 정답 9개와 다른 숫자 21개를 중복 없이 섞음.
- 조건 추론: 두 곱셈구구에 속하고 곱셈식보다 작은 수를 조건 상자로 제시, 정답 유일성 보장.
- 같은 곱 고르기: 요청 문구, 가운데 큰 곱셈식과 곡선 화살표, 큰 선택 메뉴.
- 문장 읽고 식과 답 쓰기 신규 항목: 다양한 생활 상황에서 곱셈식 3칸과 단위가 있는 답 1칸.
- 총 10유형. 골고루 모드는 한 주기에 전 유형을 포함. 작은 입력칸·기존 점수 기록·오답 기능 유지.
- 자유 곱셈식은 두 인수를 바꾸어 입력해도 정답 인정.
## v1.2.0
- 생활 속 곱셈을 20종 이동 그림 문제로 확장: 달팽이, 토끼, 자동차, 개구리, 메뚜기, 거북이, 강아지, 고양이, 다람쥐, 말, 캥거루, 병아리, 오리, 펭귄, 로봇, 장난감 자동차, 기차, 버스, 자전거, 공.
- SVG의 각 이동 구간에 거리 표시. 구간 수를 직접 세어 `거리 × [횟수] = [총거리] (단위)`로 응답.
- 거리(2~9 또는 선택한 단)와 횟수(2~9) 무작위 생성. 생활 속 곱셈 20문제 선택 시 소재 중복 없이 전체 출제.
- 좁은 화면에서 그림 가로 스크롤, 작은 답 입력칸과 기존 다른 유형/기록 유지.
## v1.1.3
- 모든 숫자 답 입력칸을 글자보다 약간 크게 축소.
- 계산 방법 문제를 방법 ① 반복 덧셈 문장/식과 방법 ② 이전 곱에 한 묶음을 더하는 문장/도식으로 변경.
- 이전 곱→새 곱 곡선 화살표와 별도 +답칸 추가. 총 다섯 빈칸 채점 및 결과 해설 지원.
## v1.1.2
- 그림과 곱셈식: 그림 아래 반복 덧셈식과 곱셈식 두 줄에 답 입력. 묶음 수는 식에 표시하며 입력칸은 합/곱 두 개.
## v1.1.1
- 곱셈식의 차이 문제를 문장 속 빈칸 3개로 변경. 채점 결과도 같은 문장으로 표시.
## v1.1.0
- 사진을 참고한 자체 문제 8종: 그림→식, 곱셈식 차이, 계산 방법, 복수 선택, 숫자판, 조건 추론, 곱 연결, 생활 문장제.
- 8/10/20문제, 단·유형 선택, 매 평가 무작위 생성.
- 이전 답 유지, 다중 입력과 집합 채점, 해설, 오답 재도전.
- 한 문제의 모든 하위 답이 맞으면 정답 처리. 오답 연습은 평가 기록에 중복 저장하지 않음.
- 숫자판은 11~35에서 선택한 단의 1~9배를 찾음. 조건/연결에는 다른 단도 사용.
