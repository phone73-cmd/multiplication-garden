# 받아쓰기 공책 모듈 · 배움정원 v1.6.1

기준 자료: 사용자가 제공한 dictation-note-v1.1.4.zip. 원본 저장소는 수정하지 않았습니다.

100문항과 dictation-* 저장 키를 유지합니다. 공통 로그인 후 dictation.js의 mount(host)로 같은 문서에 표시합니다. iframe 없이 Shadow DOM으로 공책 스타일과 ID를 격리하며 문서 스크롤을 공유합니다.

밝기·색상은 공통 appearance.js에서 관리하며 부모 CSS 변수를 그대로 상속합니다. 과목 안에는 학습 설정만 남깁니다. 급수 선택 버튼은 급수 목록에서 숨기고, 버전은 공통 하단에만 표시합니다. destroy()에서 음성·타이머·애니메이션·음성 이벤트·오디오 자원을 정리합니다.

기존 dictation/index.html 직접 주소는 공통 입구로 연결합니다. 독립 manifest/서비스워커를 등록하지 않습니다. 문장 변경 후 같은 번호의 기존 기록이 남는 정책은 유지됩니다.
